# 🛂 短期到加拿大大學做研究：入境小抄

以下是公開資訊整理，**實際要求以 IRCC（加拿大移民部）官網和你的接待單位為準**。

## 🪪 eTA 還是簽證（TRV）？

- 免簽國家護照（例如台灣一般護照，須有身分證字號）→ 搭機入境只需 **eTA**
- eTA 只在 [canada.ca](https://www.canada.ca/en/immigration-refugees-citizenship/services/visit-canada/eta.html) 申請，避開代辦網站

## 🔬 120 天研究人員工作許可豁免

- 在加拿大公立、可授予學位的大學（或其附屬研究機構）**只做研究**，可免申請工作許可，最長 120 天
- 每 12 個月只能用一次
- 官方說明：[Work permit exemptions – Global Skills Strategy](https://www.canada.ca/en/immigration-refugees-citizenship/services/work-canada/hire-temporary-foreign/global-skills-strategy/exemptions.html)

## 🧳 隨身文件（登機手提，不要托運）

- [ ] 護照＋eTA
- [ ] 接待單位的邀請信（期間、研究內容）
- [ ] 學校給邊境官員的說明信（McGill 會提供 CBSA 用的 Appendix A）
- [ ] 原單位的英文在職證明＋費用負擔證明

## 🏁 入境時

1. 出示邀請信與說明信，說明適用 120 天研究豁免
2. 請官員核發 **Visitor Record（IMM 1097）**，註明「120-day Work Permit Exemption – Public Policy」
3. **離開櫃台前確認註記**，出關後很難補
