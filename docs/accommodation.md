# 🏨 住宿比較：McGill 化學館步行圈

條件：**走路到 [Otto Maass Chemistry Building（801 Sherbrooke St W）](https://www.google.com/maps/search/?api=1&query=Otto+Maass+Chemistry+Building+McGill)**、冬季住約 5 週、含稅每晚 ≤ **CAD 310**、能自己下廚、有健身房更好、要有正式收據。

## 🥇 推薦順序（優先：小廚房＋健身房）

### 1. Hôtel Le Cantlie Suites ⭐
- 📍 1110 Sherbrooke St W（Peel 街角）｜步行約 7 分鐘
- 🍳 **Deluxe Studio 1 King** 有完整 walk-in 廚房（全尺寸家電、爐台烤箱）；最便宜的 Studio 1 King 只有小廚房（微波爐、冰箱，**沒有爐台**）
- 🥐 早餐另外付費（自助餐約 CAD 25.5）
- 💰 **2027/1 入住 36 晚實價：Deluxe Studio 含稅 ≈ CAD 217／晚**，官網直訂 12% off；入住 48 小時前免費取消
- 🏋️ 有健身房（偏小、設備較舊）；泳池只在夏天開
- 👍 房間大、隔音好、床舒服
- 📷 [Google Maps 照片](https://maps.google.com/?cid=9907050724386320025)｜[官網](http://www.hotelcantlie.com/)

### 2. Residence Inn by Marriott Montréal Downtown
- 📍 2045 Rue Peel｜步行約 6 分鐘，Peel 地鐵站旁
- 🍳 每間都有完整廚房、大冰箱；有自助洗衣房
- 🏋️ 24 小時健身房
- 📷 [Google Maps 照片](https://maps.google.com/?cid=16845641953501163360)｜[官網照片](https://www.marriott.com/en-us/hotels/yulri-residence-inn-montreal-downtown/photos/)
- 🥐 含免費早餐
- 💰 **2027/1 入住 36 晚實價：Studio Suite 長住方案（30 晚以上）含稅 ≈ CAD 206／晚**；入住前幾天內可免費取消
- 📕 小紅書（TT77, 4/6）：位置方便，但其實不便宜，作者建議改訂附近的喜來登

### 3. L'Appartement Hôtel ⚠️
- 📍 455 Sherbrooke St W｜步行約 5 分鐘
- 🍳 公寓式，有完整廚房；🥐 含早餐
- 💰 評論者實付約 CAD 222／晚（未稅）
- 🏋️ 有健身房＋頂樓室內泳池
- ⚠️ 有評論抱怨天冷時房間暖氣不足 → **一月要先問清楚暖氣**
- 📷 [Google Maps 照片](https://maps.google.com/?cid=454884633131937210)｜[官網](http://www.appartementhotel.com/)

## 🔸 沒有廚房，但小紅書有人推薦

| 住宿 | 步行 | 小紅書重點 |
|---|---|---|
| [HONEYROSE Hotel（355 De Maisonneuve O）](https://www.google.com/maps/search/?api=1&query=HONEYROSE+Hotel+355+De+Maisonneuve+O+Montreal) | ~8 分 | MaxMon（352 讚）：原本只住一晚，住後取消其他預約再續兩晚；房間舒適、早餐菜單部分免費、15 樓有健身房和泳池 |
| [Delta Hotels Montréal（Président-Kennedy）](https://www.google.com/maps/search/?api=1&query=Delta+Hotels+Montreal+475+President-Kennedy) | ~7 分 | 出現在小紅書的蒙特婁飯店比價清單 |
| [Le Centre Sheraton（René-Lévesque）](https://www.google.com/maps/search/?api=1&query=Le+Centre+Sheraton+Montreal) | ~11 分 | 有人建議作為 Residence Inn 的替代 |

這幾家適合短住；住 5 週沒有廚房，每天外食成本高（平價餐廳加稅加小費約 CAD 30）。

## ❌ 不建議

| 住宿 | 原因 |
|---|---|
| [Campus1 MTL](https://www.google.com/maps/search/?api=1&query=Campus1+MTL+420+Sherbrooke+O+Montreal) | McGill 對面的學生宿舍，小紅書測評（7/10）是夏天入住；1 月是學生入住期 |
| 學期轉租 | 小紅書「麦吉尔 短租」的貼文大多租期 1–4 月，最短也要到 4 月底；轉租通常沒有符合報帳規定的收據 |
| [Hyatt Place Montréal Downtown](https://www.google.com/maps/search/?api=1&query=Hyatt+Place+Montreal+Downtown) | 小紅書避雷文：夏天每天音樂節吵到 11 點、周邊環境差；而且離化學館走路超過 20 分鐘 |

## 🔎 小紅書搜尋紀錄（2026-11-09）

關鍵字：麦吉尔 短租／蒙特利尔 酒店 麦吉尔 附近／蒙特利尔 酒店式公寓 厨房／蒙特利尔 downtown 酒店 推荐 冬天／蒙特利尔 长住 酒店 一个月／Le Cantlie／蒙特利尔 访学 住宿

結論：小紅書上**沒有找到 Le Cantlie 的實住心得**；長住、有廚房、步行到 McGill 的筆記很少，主要是轉租和觀光短住飯店。建議以 Le Cantlie（首選）／Residence Inn（備選）為主。

## 📝 訂房前確認清單

- [x] 查實際含稅價（Le Cantlie ≈ 217、Residence Inn ≈ 206，皆 ≤ CAD 310）
- [x] 確認房型有爐台（Le Cantlie 要選 Deluxe Studio）
- [ ] 選**可免費取消**的方案（日期可能變動）
- [ ] 收據要能看出房間費、有沒有含早餐，抬頭寫上報帳單位與姓名
- [ ] 一月暖氣是否正常（尤其 L'Appartement）
